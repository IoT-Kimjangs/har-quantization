# WISDM 원본 모델 전체 평가 결과

## 결과

Mac ARM64에서 공개 FP32 Keras 모델에 준비된 평가 구간 **5,358개 전부**를 입력했습니다. 정확도와 Macro-F1은 **논문 표 2의 표시 정밀도인 소수 셋째 자리까지 일치**했습니다.

| 지표 | 논문 표 2 | 이번 평가 | 차이(퍼센트포인트) |
| --- | ---: | ---: | ---: |
| 정확도 | 96.771% | 96.771183% | +0.000183 |
| Macro-F1 | 95.458% | 95.458161% | +0.000161 |

총 5,358개 중 **5,185개 정답, 173개 오답**입니다. 차이는 논문이 소수 셋째 자리까지만 표시한 범위 안에 있습니다. 이 정도 차이를 성능 향상으로 해석하지 않습니다.

정확도는 전체 예측 중 맞힌 비율이고, Macro-F1은 행동 6개의 F1을 같은 비중으로 평균한 값입니다. 원문의 값은 11쪽 표 2에서 확인했습니다. 15쪽 구조 비교 표의 반올림된 F1을 기준값으로 사용하지 않았습니다.

## 실행 조건과 기록

- 실행일: 2026-11-05, Mac ARM64, CPU
- Python 3.12.14, TensorFlow 2.21.0, Keras 3.13.2
- 입력: 표준화된 `(5358, 80, 3)` 평가 배열
- 호출: `model(x, training=False)`, 배치 256, 마지막 배치는 남은 구간 전체
- 출력의 가장 큰 값에 해당하는 행동 인덱스를 예측으로 선택
- 모델·전처리 파일의 SHA-256을 확인한 뒤 평가
- 평가 전에 scaler를 다시 맞추거나 모델을 학습하지 않음

실행 명령은 다음과 같습니다. 이미 결과가 있는 폴더는 덮어쓰지 않으므로 재실행할 때는 다른 출력 폴더를 지정합니다.

```bash
.venv/bin/python scripts/evaluate_wisdm.py --output results/2026-11-05-macos-wisdm-fp32
```

필요한 선행 준비는 Mac 환경(PR #4), 저장 모델·호환 레이어(PR #5), 원본 데이터(PR #6), 분할·표준화 산출물(PR #7)입니다. 평가 PR은 #7 위에 올린 후속 작업이며, 실행하려면 #5의 모델 로드 코드도 필요합니다.

| 행동 | 평가 구간 수 | F1 |

| 계단 내려가기 | 500 | 88.842544% |

계단 내려가기 56개가 올라가기로, 올라가기 22개가 내려가기로 분류됐습니다. 전체 오답 173개 중 78개가 두 계단 행동 사이 혼동입니다.

## 검증과 해석

scikit-learn으로 계산한 정확도·Macro-F1을 혼동행렬로 별도 계산한 값과 비교해 일치를 확인했습니다. 저장한 예측 CSV도 5,358행과 정답 5,185개를 다시 확인했습니다. 모든 예측 확률이 유한하며 각 샘플의 합이 1에 가까운지도 검사했습니다.

**현재 저장 모델을 공개 코드 기준 평가셋에 적용했을 때 논문이 보고한 두 지표를 재현했습니다.** 원본 학습 때의 scaler·분할 인덱스가 공개돼 있지 않으므로, 수치 일치만으로 과거 학습 산출물까지 완전히 동일하다고 증명하는 것은 아닙니다. 기존의 구간 단위 분할과 학습·평가 사이 사용자·인접 구간 중첩이라는 조건도 그대로 유지합니다.
