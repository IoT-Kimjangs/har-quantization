## 1. 연구 배경 및 문제 정의

### 1.1 연구 배경

센서 기반 인간 행동 인식(Human Activity Recognition, HAR) 분야에서는 CNN, RNN, LSTM 등 딥러닝 모델을 활용하여 행동 분류 성능을 개선하는 연구가 진행되어 왔다.

최근에는 시계열 데이터의 장기적인 시간적 관계를 학습할 수 있는 Transformer 기반 접근도 활용되고 있다.

그러나 딥러닝 모델을 웨어러블 및 IoT 기기와 같은 자원 제약 환경에 배포할 경우, 모델 크기와 연산량, 추론 지연시간이 실제 활용에 제약 요인으로 작용할 수 있다.

따라서 행동 인식 정확도뿐 아니라 제한된 하드웨어 환경에서의 실행 효율을 함께 고려한 모델 설계가 필요하다.

### 1.2 기존 연구의 문제점

논문에서는 기존 연구의 주요 한계를 다음과 같이 제시한다.

1. **Transformer의 자원 효율 문제:** 시간적 관계 학습 능력과 경량화를 함께 고려한 모델 설계 필요
2. **양자화 방식별 비교 부족:** Transformer 기반 HAR 모델을 대상으로 다양한 TensorFlow Lite 정밀도 설정을 체계적으로 평가한 연구 부족
3. **성능 평가의 한계:** 행동 인식 정확도뿐 아니라 모델 크기와 추론 지연시간 사이의 상충관계를 함께 분석할 필요
4. **실제 배포 검증 부족:** 다양한 임베디드 하드웨어에서의 성능 검증이 제한적이며, 소프트웨어 수준의 평가에 의존하는 연구 존재

### 1.3 연구 목적

본 논문은 패치 기반 경량 Transformer 모델을 설계하고 TensorFlow Lite의 여러 양자화 방식을 적용하여, 행동 인식 정확도와 실행 효율 사이의 상충관계를 분석하는 것을 목적으로 한다.

이를 위해 WISDM과 PAMAP2 데이터셋을 활용하고, 모델 구조 및 양자화 정밀도에 따른 정확도, 모델 크기, 추론 지연시간을 비교한다.

> **참고:** 원논문 Abstract 및 Introduction, pp. 1–3

## 2. 논문의 제안 방법

### 2.1 패치 기반 Transformer 구조

본 논문에서는 센서 시계열 데이터의 시간적 관계를 효율적으로 학습하기 위해 패치 기반 경량 Transformer 구조를 제안한다.

기존 Transformer가 입력 시계열의 각 시점에 대해 Attention을 수행할 수 있는 것과 달리, 제안 모델은 입력을 일정한 길이의 시간적 패치로 분할하여 Transformer에 전달하는 방식을 사용한다.

패치 임베딩에는 Conv1D를 적용하며, 커널 크기와 스트라이드를 패치 길이와 동일하게 설정하여 겹치지 않는 패치 표현을 생성한다.

이러한 구조는 Attention 연산에 입력되는 토큰 수를 감소시켜 연산 부담을 줄이는 데 목적이 있다.

### 2.2 모델의 주요 구성

제안 모델은 다음과 같은 과정으로 행동을 분류한다.

**센서 시계열 입력 → 패치 임베딩 → 위치 임베딩 → Transformer Encoder → Global Average Pooling → Softmax 분류**

| 구성 요소 | 주요 역할 |
|---|---|
| **Patch Embedding** | 시계열을 패치 단위로 분할하고 특징 벡터로 변환 |
| **Positional Embedding** | 패치의 시간적 순서 정보 추가 |
| **Multi-Head Self-Attention** | 패치 사이의 시간적 관계 학습 |
| **Feed Forward Network** | Attention 결과를 추가로 변환하여 특징 학습 |
| **Global Average Pooling** | 패치별 특징을 하나의 벡터로 통합 |
| **Softmax Classifier** | 최종 행동 범주 예측 |

### 2.3 패치 길이 및 Encoder 깊이 최적화

논문에서는 패치 길이(Patch Length)와 Transformer Encoder 깊이(Encoder Depth)를 변화시키는 Ablation Study를 수행하여 모델 구성에 따른 정확도와 추론 지연시간을 분석하였다.

짧은 패치는 세밀한 시간적 특징을 유지할 수 있으나 연산 부담이 증가할 수 있으며, 긴 패치는 연산량을 줄일 수 있지만 세부적인 움직임 정보를 손실할 가능성이 있다.

또한 Encoder 깊이가 증가하면 복잡한 시간적 관계를 학습할 수 있지만, 일정 수준 이후에는 정확도 향상이 제한적인 반면 추론 지연시간이 증가할 수 있다.

실험 결과를 바탕으로 WISDM에는 패치 길이 8, Encoder 깊이 2를, PAMAP2에는 패치 길이 10, Encoder 깊이 3을 선택하였다.

| 데이터셋 | 입력 크기 | 패치 길이 | Encoder 깊이 |
|---|---|---|---|
| **WISDM** | 80 × 3 | 8 | 2 |
| **PAMAP2** | 200 × 19 | 10 | 3 |

이는 인식 정확도와 모델 실행 효율 사이의 균형을 고려한 구성이다.

### 2.4 TensorFlow Lite 기반 모델 양자화

본 논문에서는 학습된 패치 기반 Transformer 모델의 저장 공간 및 추론 효율을 개선하기 위해 TensorFlow Lite 기반 학습 후 양자화(Post-Training Quantization, PTQ)를 적용하였다.

양자화는 모델의 가중치와 활성화값을 더 낮은 정밀도로 표현하여 메모리 사용량과 연산 부담을 줄이는 최적화 기법이다.

논문에서는 다음 네 가지 모델 형식을 비교하였다.

| 모델 형식 | 주요 특징 |
|---|---|
| **FP32** | 32비트 부동소수점 기반의 비교 기준 모델 |
| **FP16** | 가중치를 16비트 부동소수점으로 변환하여 모델 크기 감소 |
| **INT8 Dynamic Range** | 가중치를 8비트 정수로 표현하고 활성화값을 실행 중 동적으로 처리 |
| **INT8 Full Integer** | 가중치와 활성화값에 정수 양자화를 적용하여 정수 연산 기반 실행을 목표로 함 |

FP16은 FP32 대비 가중치 저장에 필요한 공간을 줄일 수 있으나, 실제 추론 속도는 하드웨어와 실행 환경의 영향을 받는다.

INT8 Dynamic Range는 대표 데이터셋을 이용한 별도 보정 없이 가중치를 양자화하는 방식이며, INT8 Full Integer는 활성화값의 양자화 범위를 결정하기 위해 대표 데이터를 이용한 보정 과정이 필요하다.

본 논문에서는 Full Integer 양자화를 위해 최대 300개의 학습 데이터 윈도우를 보정에 활용하였다.

양자화 적용 후에는 행동 인식 정확도, 모델 크기, 추론 지연시간 및 처리량을 비교하여 각 정밀도 설정이 성능에 미치는 영향을 분석하였다.

**분석 관점:** 양자화에 따른 모델 크기 감소가 반드시 추론 속도 개선으로 이어지는 것은 아니므로, 각 모델의 실행 효율은 동일한 런타임 및 측정 조건에서 비교할 필요가 있다.

> **참고:** 원논문 Model Architecture, pp. 7–9 / Model Quantization for Edge Deployment, pp. 9–10 / Ablation Study, pp. 14–16

## 3. 실험 구성

### 3.1 실험 데이터셋

본 논문은 WISDM과 PAMAP2 데이터셋을 사용하여 패치 기반 Transformer 모델의 행동 인식 성능 및 양자화 효과를 평가하였다.

| 항목 | WISDM | PAMAP2 |
|---|---|---|
| **데이터 특성** | 스마트폰 가속도 데이터 | 다중 웨어러블 센서 데이터 |
| **참여자 수** | 36명 | 9명 |
| **샘플링 주파수** | 20Hz | 100Hz |
| **모델 입력 크기** | 80 × 3 | 200 × 19 |
| **윈도우 길이** | 80개 시점 | 200개 시점 |
| **윈도우 이동 간격** | 40개 시점 | 100개 시점 |

두 데이터셋은 센서 구성과 입력 차원이 다르므로 모델의 구조적 효율성과 양자화 영향을 서로 다른 조건에서 평가하는 데 활용되었다.

### 3.2 데이터 전처리

논문에서는 원시 센서 데이터를 모델 학습에 적합한 형태로 변환하기 위해 다음 과정을 적용하였다.

1. **데이터 정제:** 결측값과 유효하지 않은 센서 데이터 제거
2. **시계열 정렬:** 사용자 및 타임스탬프를 기준으로 데이터 정렬
3. **슬라이딩 윈도우 분할:** 50% 중첩된 고정 길이 윈도우 생성
4. **표준화:** 학습 데이터에서 산출한 평균과 표준편차를 이용하여 센서 특징 정규화
5. **레이블 인코딩:** 행동 범주를 숫자형 클래스로 변환

생성된 윈도우는 클래스 분포를 고려한 80:20 비율로 학습용과 테스트용 데이터로 분할하였다.

### 3.3 모델 학습 및 실행 환경

| 항목 | 설정 |
|---|---|
| **운영체제** | Windows 10 Pro |
| **CPU** | Intel Xeon Silver 4208 |
| **메모리** | 64GB |
| **학습 프레임워크** | TensorFlow / Keras |
| **모델 변환 및 추론** | TensorFlow Lite |
| **Optimizer** | Adam |
| **Learning Rate** | 0.001 |
| **Loss Function** | Sparse Categorical Cross-Entropy |
| **Epoch** | 최대 40 |
| **Batch Size** | WISDM 128 / PAMAP2 64 |
| **Early Stopping** | Patience 6 |

학습된 Transformer 모델은 TensorFlow Lite를 통해 FP32, FP16, INT8 Dynamic Range, INT8 Full Integer 형식으로 변환하였다.

INT8 Full Integer 양자화에서는 최대 300개의 학습 윈도우를 대표 데이터로 사용하였다.

추론시간은 TFLite Interpreter에서 워밍업 실행 후 측정하였다. 실험은 CPU 기반 환경에서 수행되었으며, 실제 임베디드 하드웨어에서 직접 측정한 결과는 아니다.

> **참고:** 원논문 Methodology 및 Experimental Setup, pp. 4–10

## 4. 주요 실험 결과

### 4.1 기준 모델의 성능

패치 기반 Transformer의 원본 모델은 WISDM에서 96.771%, PAMAP2에서 98.480%의 행동 인식 정확도를 달성하였다.

| 데이터셋 | 정확도 | Macro-F1 | 모델 크기 | 추론시간 |
|---|---:|---:|---:|---:|
| **WISDM** | 96.771% | 95.458% | 2,474.41 KB | 108.20 ms |
| **PAMAP2** | 98.480% | 97.978% | 3,081.14 KB | 114.60 ms |

이는 양자화 모델과 비교하기 위한 기준 모델의 성능이다.

### 4.2 양자화 방식별 모델 크기 및 추론시간

#### WISDM

| 모델 | 크기(KB) | 추론시간(ms) |
|---|---:|---:|
| **TFLite FP32** | 295.20 | 0.22 |
| **TFLite FP16** | 163.63 | 0.21 |
| **TFLite INT8 Dynamic** | 110.05 | 0.86 |
| **TFLite INT8 Full** | 116.52 | 9.73 |

#### PAMAP2

| 모델 | 크기(KB) | 추론시간(ms) |
|---|---:|---:|
| **TFLite FP32** | 995.71 | 0.33 |
| **TFLite FP16** | 520.55 | 0.36 |
| **TFLite INT8 Dynamic** | 314.27 | 0.26 |
| **TFLite INT8 Full** | 325.07 | 2.40 |

INT8 Dynamic은 두 데이터셋에서 비교한 TFLite 모델 중 가장 작은 크기를 기록하였다.

그러나 추론시간에서는 데이터셋과 양자화 방식에 따른 차이가 나타났다. WISDM에서는 FP16이 가장 짧은 추론시간을 보였으며, PAMAP2에서는 INT8 Dynamic이 가장 짧았다.

INT8 Full은 두 데이터셋 모두 TFLite FP32 대비 추론 지연시간이 증가하였다.

### 4.3 양자화에 따른 정확도 변화

| 데이터셋 | TFLite FP32 | TFLite INT8 Dynamic | TFLite INT8 Full |
|---|---:|---:|---:|
| **WISDM** | 96.771% | 96.789% | 96.771% |
| **PAMAP2** | 98.480% | 98.379% | 97.974% |

양자화 이후에도 높은 행동 인식 정확도가 유지되었다.

다만 PAMAP2에서는 INT8 Full의 정확도가 TFLite FP32 대비 0.506%p 감소하여, 양자화 정밀도에 따라 성능 저하 정도가 달라질 수 있음을 확인하였다.

### 4.4 결과 해석 시 고려사항

논문은 INT8 Dynamic의 모델 크기가 원본 모델 대비 WISDM에서 95.55%, PAMAP2에서 89.80% 감소했다고 보고하였다.

또한 Keras 원본 모델 대비 추론 지연시간이 약 99% 감소한 결과를 제시하였다.

그러나 이러한 비교에는 모델 형식 및 실행 런타임의 변화가 함께 포함되어 있다.

실제로 같은 TFLite 런타임에서 FP32와 INT8 Dynamic을 비교하면 WISDM에서는 추론시간이 0.22ms에서 0.86ms로 증가했으며, PAMAP2에서는 0.33ms에서 0.26ms로 감소하였다.

따라서 원본 모델에서 TFLite로 변환하는 과정의 영향과 양자화 정밀도 변경의 영향을 구분하여 해석할 필요가 있다.

**핵심:** 모델 크기 감소는 두 데이터셋에서 확인되었으나, 추론 속도 개선 정도는 실행 런타임과 양자화 방식에 따라 달라졌다.

> **참고:** 원논문 Tables 2–8, pp. 11–12

## 5. 논문의 한계 분석

본 논문은 패치 기반 Transformer 구조와 TensorFlow Lite 양자화를 활용하여 높은 행동 인식 정확도를 유지하면서 모델 크기를 감소시킬 수 있음을 보여준다.

그러나 양자화에 따른 추론 지연시간 개선 효과, 데이터 분할 방식 및 실제 하드웨어 검증 측면에서 추가적인 분석이 필요하다.

### 5.1 양자화와 런타임 변환 효과의 구분

논문은 INT8 Dynamic 양자화 모델의 추론 지연시간이 Keras 원본 모델 대비 약 99% 감소한 결과를 제시하였다.

그러나 이러한 비교에는 모델의 수치 정밀도 변화뿐 아니라 Keras에서 TensorFlow Lite로의 실행 형식 및 런타임 변화가 함께 포함되어 있다.

특히 같은 TFLite 환경에서 FP32와 INT8 Dynamic 모델을 비교하면 데이터셋에 따라 결과가 달라진다.

| 데이터셋 | TFLite FP32 | TFLite INT8 Dynamic | 비교 결과 |
|---|---:|---:|---|
| **WISDM** | 0.22 ms | 0.86 ms | 지연시간 증가 |
| **PAMAP2** | 0.33 ms | 0.26 ms | 지연시간 감소 |

따라서 원본 모델 대비 지연시간 감소를 양자화만의 효과로 해석하는 것은 제한적이다.

양자화 자체의 효과를 분석하기 위해서는 동일한 실행 환경에서 FP32와 양자화 모델을 비교하고, 런타임 변경에 따른 차이를 별도로 검토할 필요가 있다.

### 5.2 실제 임베디드 하드웨어 검증 부족

논문의 추론 성능 평가는 Intel Xeon Silver 4208 CPU와 Windows 10 환경에서 수행되었다.

따라서 제시된 추론시간은 실제 MCU 또는 웨어러블 기기에서 직접 측정한 성능이 아니다.

실제 임베디드 환경에서는 CPU 구조, 연산 지원 방식, 메모리 용량 및 실행 라이브러리에 따라 모델 성능이 달라질 수 있다.

이에 따라 논문에서 제시한 결과만으로 실제 자원 제약 기기에서의 배포 성능을 확정하기는 어렵다.

저자 역시 Raspberry Pi, NVIDIA Jetson 및 ARM 기반 마이크로컨트롤러에서의 추가 검증 필요성을 제시하였다.

### 5.3 데이터 분할 방식과 일반화 성능

논문에서는 연속적인 센서 데이터를 50% 중첩된 슬라이딩 윈도우로 분할한 후, 생성된 윈도우를 학습용 80%와 테스트용 20%로 나누었다고 설명한다.

이러한 방식에서는 서로 인접한 윈도우가 일부 센서 데이터를 공유할 수 있으므로, 학습 데이터와 테스트 데이터 사이에 유사하거나 중첩된 구간이 포함될 가능성을 검토해야 한다.

또한 사용자 단위로 학습 및 테스트 데이터를 분리한 평가 결과가 제시되지 않아, 학습에 참여하지 않은 새로운 사용자에 대한 일반화 성능을 판단하는 데 한계가 있다.

다만 실제 데이터 누수 여부는 데이터 분할 코드와 처리 순서를 확인하여 검증해야 한다.

따라서 사용자 독립적인 데이터 분할 및 중첩 구간 분리를 고려한 추가 평가가 필요하다.

### 5.4 실제 자원 사용량 평가의 한계

논문은 양자화 방식에 따른 모델 크기, 추론 지연시간 및 처리량을 비교하였다.

그러나 모델 파일 크기는 실제 추론 과정에서 필요한 최대 RAM 사용량과 동일하지 않으며, CPU 기반 추론시간만으로 배터리 기반 기기의 에너지 효율성을 판단하기도 어렵다.

따라서 실제 배포 가능성을 평가하기 위해서는 대상 하드웨어에서의 최대 메모리 사용량과 에너지 소비량 등을 추가로 측정할 필요가 있다.

### 5.5 한계 분석 종합

| 분석 항목 | 논문에서 확인된 내용 | 추가 검증 필요사항 |
|---|---|---|
| **추론 지연시간** | 원본 모델 대비 큰 폭의 지연시간 감소 보고 | 런타임 변경과 양자화 효과 구분 |
| **하드웨어 검증** | Windows CPU 기반 TFLite 벤치마킹 | 실제 임베디드 기기에서 성능 측정 |
| **데이터 분할** | 중첩 윈도우 생성 후 80:20 분할 | 데이터 중첩 가능성과 사용자 독립 평가 검토 |
| **자원 효율** | 모델 크기·지연시간·처리량 비교 | Peak RAM 및 에너지 소비 검증 |

**핵심:** 본 논문은 양자화를 통한 HAR 모델 경량화 가능성을 제시하였으나, 런타임 변환과 양자화 효과의 구분, 데이터 분할에 따른 일반화 성능 및 실제 하드웨어에서의 배포 효율을 추가로 검증할 필요가 있다.

## 6. 본 프로젝트의 확장 방향

### 6.1 확장 연구의 목적

본 프로젝트는 패치 기반 Transformer HAR 모델의 양자화 효과를 재현하고, 실행 환경 및 측정 기준에 따른 성능 차이를 추가로 분석하는 것을 목적으로 한다.

원논문은 TensorFlow Lite 양자화를 통해 모델 크기와 추론 지연시간이 개선된 결과를 보고하였으나, 원본 모델과 양자화 모델의 비교에는 런타임 변환 효과가 함께 포함되어 있다.

이에 따라 본 프로젝트에서는 런타임 변환과 양자화 정밀도 변경의 영향을 단계적으로 비교하고, 서로 다른 PC 환경에서 경량화 효과가 어떻게 나타나는지 검토하고자 한다.

### 6.2 런타임 변환과 양자화 효과의 구분

원논문에서 제시된 큰 폭의 추론 지연시간 감소를 정확하게 해석하기 위해 다음과 같이 비교 단계를 구분한다.

| 비교 단계 | 비교 대상 | 분석 목적 |
|---|---|---|
| **1단계** | Keras 원본 ↔ TFLite FP32 | 모델 변환 및 런타임 변경에 따른 성능 차이 분석 |
| **2단계** | TFLite FP32 ↔ TFLite FP16 | 부동소수점 정밀도 축소의 영향 분석 |
| **3단계** | TFLite FP32 ↔ TFLite INT8 Dynamic | 동적 범위 양자화의 영향 분석 |
| **4단계** | TFLite FP32 ↔ TFLite INT8 Full | 전체 정수 양자화의 영향 분석 |

각 비교에서는 동일한 입력 데이터와 일관된 측정 규약을 적용하고, 모델의 정확도, 파일 크기, 추론 지연시간을 분석한다.

특히 TFLite FP32를 기준으로 양자화 모델의 성능을 비교하여, 런타임 변경이 포함된 원본 모델 대비 개선율과 구분하고자 한다.

### 6.3 플랫폼별 성능 비교

원논문은 Windows 기반 Intel Xeon CPU 환경에서 추론 성능을 평가하였다.

본 프로젝트에서는 Mac(ARM 계열)과 Windows(x86-64 계열) 환경에서 동일한 모델 형식에 대한 추론 성능을 비교한다.

| 비교 항목 | 분석 내용 |
|---|---|
| **실행 환경** | 운영체제 및 CPU 아키텍처에 따른 성능 차이 |
| **모델 형식** | Keras, TFLite FP32, FP16, INT8 Dynamic, INT8 Full |
| **추론 지연시간** | 실행 환경별 양자화 방식의 지연시간 비교 |
| **정확도** | 모델 변환 및 양자화 이후 행동 인식 성능 변화 |
| **메모리 사용량** | 측정 가능한 실행 메모리 지표 비교 |

각 플랫폼의 측정 결과를 원논문과 비교하여, 양자화 방식별 효율성이 실행 환경에 따라 달라지는지 분석한다.

다만 Mac과 Windows 환경은 운영체제뿐 아니라 CPU 아키텍처 및 실행 라이브러리도 다를 수 있으므로, 결과 차이를 단일 요인의 영향으로 단정하지 않는다.

### 6.4 경량화 성능의 정량적 분석 및 시각화

양자화 전후의 효율을 비교하기 위해 모델 크기, 추론 지연시간 및 행동 인식 정확도를 주요 분석 지표로 활용한다.

모델 크기의 감소율과 추론시간 변화율은 기준 모델을 명시하여 계산하며, 원본 Keras 모델 대비 결과와 TFLite FP32 대비 결과를 구분한다.

이를 바탕으로 다음과 같은 시각화를 수행한다.

1. **모델 크기 비교:** 데이터셋 및 양자화 방식별 모델 파일 크기 비교
2. **추론 지연시간 비교:** 플랫폼별·모델 형식별 지연시간 비교
3. **정확도 변화 분석:** 양자화 전후 행동 인식 성능 변화 확인
4. **압축과 실행 효율의 관계 분석:** 모델 크기 감소와 지연시간 개선의 관계 검토

단순히 압축률이 높은 모델을 우수하다고 판단하기보다, 정확도 유지 여부와 실제 추론 효율을 종합하여 평가하고자 한다.

### 6.5 프로젝트의 범위 및 한계

본 프로젝트는 Mac 및 Windows 기반 PC 환경에서 모델 변환과 양자화 효과를 분석한다.

따라서 다음 사항은 실험 결과 해석 시 구분할 필요가 있다.

- PC에서 측정한 추론시간은 실제 MCU 및 웨어러블 기기의 실행 성능을 직접 입증하지 않음
- 프로세스 수준의 메모리 측정값은 임베디드 기기에서 요구되는 Peak RAM과 동일한 지표가 아닐 수 있음
- 실제 센서 연결 환경에서의 에너지 소비 및 장기적 동작 안정성은 별도로 검증하지 않음
- 데이터 분할에 따른 사용자 독립적 일반화 성능은 본 프로젝트의 주요 실험 범위와 구분하여 해석함

따라서 본 프로젝트는 실제 임베디드 기기 배포 자체를 검증하기보다, 양자화 효과의 해석과 실행 환경별 성능 차이에 초점을 맞춘다.

### 6.6 종합

본 프로젝트는 원논문의 패치 기반 Transformer HAR 모델과 TensorFlow Lite 양자화 방식을 활용하여, 모델 경량화가 실제 실행 효율에 미치는 영향을 추가적으로 분석한다.

특히 원본 모델과 TFLite 모델 간의 실행 성능 차이를 구분하고, 동일한 TFLite 런타임에서 정밀도 변경에 따른 효과를 비교한다는 점에 의의가 있다.

이를 통해 모델 크기 감소와 추론 지연시간 개선이 항상 일치하지 않을 수 있음을 검증하고, HAR 모델 경량화 성능을 해석할 때 고려해야 할 실행 환경과 평가 기준을 제시하고자 한다.
