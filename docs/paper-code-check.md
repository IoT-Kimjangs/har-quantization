# 논문·공개 코드·현재 실험 대조표

## 먼저 읽을 결론

**현재 진행한 WISDM 데이터 준비·분할·표준화는 논문에 명시된 핵심 절차와 일치합니다.** 공개 코드뿐 아니라 제공된 논문의 원문도 대조했습니다. 저장 모델의 입력 크기, 패치 길이와 인코더 수 역시 논문의 선택 설정에 맞습니다.

다만 논문에는 실제 학습 때 사용한 평균·표준편차와 분할 인덱스가 없습니다. 따라서 지금 계산한 통계를 **논문·공개 코드의 절차로 재계산한 통계**라고 부릅니다. 공개 모델의 실제 학습 통계와 수치까지 같다고 확정할 근거는 아직 없습니다. 이것은 현재 절차가 논문과 다르다는 뜻이 아닙니다.

예를 들어 논문이 “학습 데이터의 평균을 빼라”고 설명하면 그 방법은 확인할 수 있습니다. 하지만 학습 때 사용한 평균 숫자가 실려 있지 않으면, 우리가 얻은 숫자가 저자의 숫자와 같은지 직접 대조할 수는 없습니다.

현재 다음 단계인 샘플 예측을 진행하는 데 이 구분이 장애가 되지는 않습니다. 실제 예측 결과를 기록하면서 출처와 확인 범위를 함께 남기면 됩니다.

## 두 논문은 각각 어떤 역할인가?

| 자료 | 우리가 확인할 내용 | 이번에 확인한 위치 |
| --- | --- | --- |
| *Edge efficient human activity recognition using a quantized patch based transformer* | 재현할 모델의 데이터·전처리·분할·구조·학습·변환 조건 | 7~11쪽, 15쪽, 19쪽 |
| *A Review of TinyML for Human Activity Recognition on Edge Devices* | 무엇을 기록해야 실험을 공정하게 비교할 수 있는지 | 16쪽 표 4, 38쪽 6.6절 |

서베이는 이 Transformer 모델의 학습 기록을 증명하는 자료가 아닙니다. 서베이에서는 구간 길이·전처리·사용자 분할·실행 환경·지연시간의 측정 범위를 함께 기록해야 한다고 설명합니다. 우리는 이 기준으로 재현 기록과 Mac·Windows 비교 실험을 구성합니다.

## 학습·양자화·측정 조건도 확인했는가?

아래는 논문과 저자 코드의 대조입니다. **우리 모델 재학습·양자화·속도 측정을 완료했다는 뜻은 아닙니다.**

| 학습 | 10쪽 표 1·본문: Adam, 초기 학습률 0.001, sparse categorical cross-entropy, 최대 40 epoch, WISDM 배치 128 | 기준 코드 셀 7~8에 같은 설정 | 명시 조건 일치 |

| 양자화 종류 | 9~10쪽: FP32·FP16·동적 INT8·전체 정수 INT8 | 양자화 노트북 셀 2에서 4가지 변환 설정 | 설정 일치; 우리 변환 실행 전 |

| TFLite 지연시간 | 10쪽: 워밍업 뒤 반복 추론 측정 | 양자화 코드에서 워밍업 40회·측정 250회 | 방식은 맞음; 횟수는 코드에서 보완 |

우리 계획의 워밍업 50회·측정 1,000회, 1스레드·기본 설정 비교, Keras 직접 호출 추가는 **동일 조건 비교를 위한 우리 확장 설정**입니다. 원 논문 코드 그대로의 측정 횟수라고 쓰지 않습니다. 원본 방식과 우리 공통 조건의 측정을 구분해 기록합니다.

## 논문만으로는 확정할 수 없는 부분

| 질문 | 확인한 근거 | 결론 |
| --- | --- | --- |
| 지금 가져온 GitHub가 논문에서 가리킨 코드인가? | 19쪽 Code availability가 같은 저장소를 가리킴 | 저장소 출처 확인 |
| 내려받은 모델 구조가 선택 모델에 맞는가? | 저장 모델 config의 입력·Conv1D·인코더 수를 논문과 비교 | 확인한 구조 일치 |
| 모델 파일 크기도 맞는가? | 현재 파일 2,533,793바이트 ÷ 1,024 = 약 2,474.41, 11쪽 표 4의 WISDM 2,474.41KB와 일치 | 반올림한 크기 일치; 학습 이력 증명은 아님 |
| 학습 당시 평균·표준편차와 지금 값이 같은가? | 논문에 해당 수치 없음. 기준 커밋에 scaler 결과 파일 없음 | 직접 대조 불가 |
| 학습·평가에 들어간 구간 번호가 완전히 같은가? | 논문은 비율·고정 난수를 설명하지만 인덱스는 없음. 원본 실행 라이브러리 버전도 특정되지 않음 | 같은 방식으로 재계산했으나 완전한 동일성은 미확인 |
| 정확도 96.771%가 재현됐는가? | 11쪽 표 2가 논문 보고값. 우리는 아직 예측·전체 평가 전 | 평가 후 확인할 항목 |

저장 파일의 해시와 학습 기록을 연결한 자료도 논문에는 없습니다. 논문 설명, 공개 코드, 저장 모델 구조가 맞는다는 근거와, 과거 학습 산출물의 완전한 동일성을 증명하는 근거는 구분합니다.

## 별도로 기록한 차이와 주의점

- **겹치는 구간의 분할:** 논문도 50% 겹치는 구간을 만든 뒤 구간 단위로 나눕니다. 현재 재현에서 학습·평가 사이에 인접 구간이 겹치는 것은 논문과 다른 분할을 적용해서 생긴 일이 아닙니다. 다만 새로운 사용자에 대한 일반화 성능을 검증한 것으로 해석하지 않습니다.
- **논문에 없는 코드의 세부 설정:** 검증 비율 0.15, 임베딩 차원 64, head 4개, FFN 차원 128, dropout 0.15 등은 코드에 있습니다. 논문이 이 숫자를 모두 명시한 것처럼 인용하지 않습니다.
- **README보다 실제 기준 노트북을 우선:** README의 WISDM 소개에는 가속도·자이로스코프가 함께 적혀 있지만, 논문과 실제 WISDM 입력은 3축 가속도입니다.
- **PAMAP2는 추가 대조 필요:** 논문 7쪽은 사용자·타임스탬프 정렬을 설명하지만, 공개 PAMAP2 기준 코드 셀 4~5는 선택한 채널을 파일별로 읽어 이어 붙인 뒤 사용자·타임스탬프를 유지하지 않고 구간을 만듭니다. WISDM과 동일하게 사용자 경계가 보존된다고 가정하지 않으며, PAMAP2 재현 단계에서 이 차이를 기록합니다.
- **양자화 용어:** 논문 9쪽 도입 문장의 INT4 표현과 달리 같은 쪽의 네 번째 항목, 10쪽 설정 및 실제 변환 코드는 INT8 전체 정수 방식입니다. 우리 재현 대상도 INT8입니다.
