## 10주차 11월 3일에서 11월 9일

목표는 두 OS에서 저장 모델 평가를 시작하는 것입니다.

- OS 담당: Python 가상환경을 만들고 공통 지원 버전의 TensorFlow·Keras·LiteRT를 확인합니다. OS·CPU·RAM·패키지 버전을 기록합니다.
- OS 담당: WISDM·PAMAP2를 공식 배포처에서 받고 로컬 경로를 설정합니다. 데이터와 모델 원본은 커밋하지 않습니다.
- 코드 담당: AddPositionEmbedding 등 필요한 커스텀 레이어를 확인하고 저장된 Keras 모델의 로드·입력 형태·출력 클래스를 점검합니다.
- 재현 담당: WISDM 윈도우 80/stride 40, PAMAP2 200/100, 80:20 분할, seed 42를 확인하고 정확도·Macro-F1의 1차 결과를 남깁니다.
- 김가은: 전처리·분할 방식과 정확도 과대평가 가능성을 논문 근거와 함께 정리합니다.
- 권장 PR: `docs: Mac 실행 환경 정리`, `docs: Windows 실행 환경 정리`, `feat: 저장 모델 평가 절차 추가`.
- 완료 기준: 각 OS에서 모델을 읽고 평가까지 실행했습니다. 실패한 항목은 오류·재현 명령·다음 조치를 이슈로 남겼습니다.

## 11주차 11월 10일에서 11월 16일

목표는 재현 결과를 정리하고 공통 측정 도구를 준비하는 것입니다.

- 코드 담당: Keras predict(), Keras model(x), TFLite FP32·FP16·INT8 동적·INT8 전체 정수의 6개 실행 경로를 준비합니다.
- 코드 담당: 배치 1, 워밍업 50회, 측정 1,000회, 중앙값·p95, 파일 크기, 독립 프로세스 피크 RSS, 1스레드/기본 설정 기록을 구현합니다.
- OS 담당: 대표 데이터·입출력 dtype·delegate를 기록하고 각 OS에서 짧은 시험 측정으로 결과 파일 형식을 맞춥니다.

- 권장 PR: `feat: 양자화 변형 측정 추가`, `feat: 지연시간과 메모리 기록 추가`, `docs: 논문 한계 분석 정리`.
- 완료 기준: 두 OS가 같은 조건·스키마로 결과를 생성하고, 재현 결과와 논문 수치의 차이를 설명할 자료가 있습니다.
