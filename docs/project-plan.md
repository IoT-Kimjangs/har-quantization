# 프로젝트 계획

주제는 초소형 IoT 센서 기반 행동 인식 모델의 양자화 효율 분석입니다. 서베이와 구현체 논문 분석을 바탕으로 공개 구현을 재현하고, 런타임 효과 분리와 교차 플랫폼 측정까지 진행합니다.

## 역할

| 담당 | 업무 |
| --- | --- |
| 김가은 | 논문 정독, 문제·한계 분석, 수행계획서·발표·보고서 총괄 |
| 서진정 | 재현·확장 코드 및 본인 OS 측정, GitHub 실행 문서 |
| 장은성 | 재현·확장 코드 및 본인 OS 측정, 결과 정리 |

서진정·장은성의 재현/확장 책임은 OS 확인 후 확정합니다. 매주 1회 30분 회의하고 결정사항을 이슈 또는 PR에 기록합니다.

## 일정

| 기간 | 작업 |
| --- | --- |
| 10/27–11/2 | 주제·논문 확정, 실행 검증 내역 정리, 계획서 제출 |
| 11/3–11/9 | Mac·Windows 환경과 데이터 준비, 저장 모델 정확도 평가 |
| 11/10–11/16 | 재학습, 논문 한계 분석, 측정 코드 확장 |
| 11/17–11/23 | 48개 조합 측정, KCI 초안 도전 여부 결정 |
| 11/24–11/29 | 분석·그래프·발표자료·GitHub 문서 정리 |
| 11/30 오전 11:59 | 발표자료 제출 |
| 12/1 | 발표 |
| 12/4 | 보고서 초안 |
| 12/14 | 보고서 최종 |

일정은 제공된 10/27 계획서를 기준으로 하며 강의 공지 변경 시 함께 수정합니다. 수행계획서의 4단계는 조사→논문 분석→구동→확장 순서로 대응합니다.

## 분석할 쟁점

런타임 차이, `predict()` 호출 오버헤드, `.keras`의 옵티마이저 상태 포함 여부, 실제 사용 위치 임베딩, INT8 연산자 지원, 겹치는 윈도우의 데이터 누수를 확인합니다. 계획서의 해석은 검증할 가설로 다루고 원본 코드와 측정 근거를 PR에 연결합니다.
