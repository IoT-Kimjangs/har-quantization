# 팀원 합류 확인

저장소를 사용하기 전에 GitHub 계정과 리뷰 담당을 맞춥니다.

- [ ] 김가은·서진정·장은성의 GitHub 아이디를 확인합니다.
- [ ] 조직 초대를 수락하고 저장소 쓰기 권한을 확인합니다.
- [ ] 작성자별 지정 리뷰어를 `.github/reviewers.json`에 등록합니다.
- [ ] 본인의 Git 작성자 이름·이메일과 GitHub 인증 계정을 확인합니다.
- [ ] Mac·Windows 환경 담당을 정하고 실행 환경을 기록합니다.
- [ ] 첫 PR에서 지정 리뷰어의 검토 내용과 Approve를 확인합니다.

현재 지정 리뷰어 목록은 계정 확인 전 상태입니다. 빈 목록으로는 `review-policy`가 통과하지 않습니다. 최초 리뷰어 등록 PR은 대상 브랜치의 기존 정책을 읽으므로 초기 계정 등록에는 관리자의 일회성 설정 절차가 필요합니다. 등록할 계정과 역할을 확정한 뒤 기존 ruleset을 삭제하지 말고 변경 범위와 절차를 기록합니다.
