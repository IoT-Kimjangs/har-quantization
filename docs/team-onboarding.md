# 팀원 합류 확인

저장소를 사용하기 전에 GitHub 계정과 리뷰 담당을 맞춥니다.

- [x] GitHub 계정 확인: 김가은 `20232541-gaeun`, 서진정 `improvv`, 장은성 `20327135`.
- [x] 조직 가입과 저장소 기여 권한 확인.
- [x] 작성자별 리뷰 후보를 `.github/reviewers.json`에 등록. 서진정의 PR은 장은성만 지정.
- [ ] 본인의 Git 작성자 이름·이메일과 GitHub 인증 계정을 확인합니다.
- [ ] Mac·Windows 환경 담당을 정하고 실행 환경을 기록합니다.
- [ ] 첫 PR에서 지정 리뷰어의 검토 내용과 Approve를 확인합니다.

작성자 외 쓰기 권한이 있는 팀원 한 명을 Reviewers에 지정합니다. 한 명이 Approve하면 머지할 수 있고 리뷰 본문은 선택입니다. 최신 main 반영이나 새 커밋에 대한 재승인을 별도 필수 조건으로 요구하지 않습니다.
